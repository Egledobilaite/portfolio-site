# Portfolio Site

A personal portfolio site.

## Rules

- The site is exactly three files: `index.html`, `style.css`, `app.js`. Do not add more files for the site.
- No frameworks (no React, Vue, Svelte, Tailwind, etc.).
- No build step. The files must work by opening `index.html` directly in a browser.
- No external libraries, CDNs, or packages. Write plain HTML, CSS, and JavaScript.

## Other files

- `about.md` is source text for the About section. Copy its content into `index.html`; do not load it at runtime.
- `IMG_1133.JPG` is the portrait photo shown at the top of the page. Image files like this are allowed alongside the three code files.
- `CLAUDE.md` is this file.
